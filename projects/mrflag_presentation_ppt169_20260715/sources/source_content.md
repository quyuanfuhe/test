# MR Flag Battle（MR夺旗大战）项目总结汇报

## 项目背景

### 开发工具与环境
- **游戏引擎**: Unity 2022.2.62f3c1（LTS）
- **目标平台**: Pico 4 Ultra Enterprise（Android）混合现实头显
- **MR SDK**: Pico Integration SDK 3.4.0
- **后端技术**: Go 语言独立服务端
- **通信协议**: HTTP REST + WebSocket + UDP
- **开发模式**: 无测试/CI/CLI构建，通过Unity Editor运行

### 游戏受众
- 混合现实（MR）体验爱好者
- Pico VR头显用户
- 双人联机对战玩家
- 对空间计算和真实环境交互感兴趣的技术用户

## 项目介绍

MR Flag Battle 是一款双人混合现实（MR）夺旗对战游戏。玩家佩戴Pico 4 Ultra Enterprise头显，在真实物理空间中看到虚拟旗帜和场景物体叠加在现实环境之上。游戏通过Video See-Through技术实现混合现实效果，利用空间锚点同步两名玩家的虚拟场景。

**核心玩法**: 在限定时间内，玩家在MR空间中抓取并收集彩色旗帜（金色、红色、白色）来获取分数。游戏支持两种模式：
- **单人模式**: 30秒限时夺旗挑战
- **双人联机模式**: 两名玩家局域网实时对战，由Go后端进行游戏逻辑仲裁

**核心功能**:
- 地图编辑器：在XR环境中使用手柄搭建自定义场景（墙壁、箱子、柱子等）
- 地图同步：自定义地图通过WebSocket上传至服务器，其他玩家自动同步
- 空间锚点：共享空间坐标系确保两名玩家看到的虚拟物体位置一致
- 实时位置同步：通过UDP MessagePack协议30Hz同步玩家位置

## 前期设计

### 游戏流程
1. 用户启动应用 → 进入主菜单（MainMenu）
2. 选择模式：Host（创建房间）/ Join（加入房间）/ Solo（单人）
3. 进入地图选择（MapSelect），可选已有地图或进入地图编辑器
4. 创建/选择地图后进入游戏场景
5. 游戏结束后显示得分，返回主菜单

### 构筑要素
- **场景物体**: 墙壁(Wall)、箱子(Box)、柱子(Pillar)、桶(Barrel)、坡道(Ramp)、球体(Sphere)
- **旗帜系统**: 金色旗(Gold Flag)、红色旗(Red Flag)、白色旗(White Flag)
- **玩家系统**: 本地玩家(LocalPlayer) 通过UDP发送位置，远程玩家(RemotePlayer) 接收并插值渲染
- **UI系统**: 主菜单面板、地图选择列表、得分显示

### 开发计划
- 第一阶段：Unity项目搭建，Pico SDK集成，基础MR环境配置
- 第二阶段：单人游戏模式实现（MRGame场景、MRFlag旗帜系统）
- 第三阶段：Go后端搭建（HTTP REST、WebSocket、UDP三层服务）
- 第四阶段：双人联机模式实现（MultiGame场景、网络同步）
- 第五阶段：地图编辑器开发（XR控制器交互、地图存储与同步）
- 第六阶段：模型替换、UI优化、Bug修复

## 最终实现

### 实现成果
项目成功实现了完整的MR夺旗游戏体验，包括：
- ✅ MR混合现实环境（Video See-Through + 空间锚点）
- ✅ 单人30秒夺旗挑战模式
- ✅ 双人实时联机对战模式
- ✅ XR手柄地图编辑器（放置、选择、编辑物体）
- ✅ 自定义地图云端同步
- ✅ HTTP REST房间管理API
- ✅ WebSocket游戏事件通信
- ✅ UDP 30Hz玩家位置同步
- ✅ 场景物体模型替换支持

### 技术亮点
- 使用Pico Spatial Anchor实现真实空间共享坐标系
- 自定义MsgPack编解码器确保UDP位置同步高效准确
- Go后端支持开发简化模式，降低联机调试门槛
